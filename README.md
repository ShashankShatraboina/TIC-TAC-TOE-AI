# Tic Tac Toe AI

Tic Tac Toe AI is an interactive game application where players can challenge an intelligent AI opponent. The project uses artificial intelligence algorithms to make strategic moves and provide a competitive gameplay experience.

## Features
- Play against an AI-powered opponent
- Smart move prediction and decision making
- Interactive and user-friendly interface
- Real-time game updates
- Lightweight and easy to run

## Technologies Used
- Python
- Machine Learning
- NumPy

## How It Works
The AI analyzes the current game board and selects the optimal move using intelligent game strategies such as the Minimax algorithm.
